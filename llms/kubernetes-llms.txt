# Kubernetes

> Kubernetes (K8s) is an open source system for automating deployment, scaling, and management of containerized applications. The Kubernetes API is the resource-based (RESTful) HTTP interface exposed by the control-plane API server; users, cluster components, and external clients all read and mutate cluster state through it using the standard HTTP verbs. It is a CNCF graduated project.

This llms.txt is generated by API Evangelist from the apis.yml catalog and the artifacts harvested into the api-evangelist/kubernetes repository. The API server is addressed in-cluster at https://kubernetes.default.svc; there is no single public base URL.

## APIs

- [Kubernetes API](https://kubernetes.io/docs/concepts/overview/kubernetes-api/): Query and manipulate the state of Kubernetes objects (Pods, Deployments, Services, Namespaces, Nodes, ConfigMaps, Secrets, RBAC, autoscaling, events) via the control-plane API server.
